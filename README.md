# NPLEY × NRED 제안서 (웹 프레젠테이션)

NRED × 디지털인사이트 지면광고 디자인 광고시안 제안서 49장을 GSAP 전환 효과로 넘겨 보는 정적 웹 페이지입니다. (`npley-spep-deck`과 같은 레이아웃·모션)

## 구성
- `index.html` — 페이지 전체(HTML·CSS·JS 한 파일). 슬라이드 데이터(`SLIDES`)와 입장 화면(아이디/비밀번호)이 스크립트 안에 들어 있음
- `assets/` — Figma 슬라이드를 내보낸 WebP (무손실)
  - `base-NN.webp` 각 장의 본문 · `thumb-NN.webp` 전체 보기용 썸네일
  - `bg-` 큰 배경 단어 · `eye-` 페이지 라벨 · `title-` 헤드라인 · `desc-` 우측 설명 (투명 레이어, 헤더가 있는 장만)
- `.nojekyll` — GitHub Pages가 Jekyll 처리하지 않도록

## 조작
←/→, 스페이스, 클릭(오른쪽 다음·왼쪽 이전), 스와이프 · G 전체 보기 · F 전체 화면 · `#s5`처럼 주소 뒤에 붙이면 해당 장으로 이동

## 입장 화면
브라우저에서만 확인하는 간단한 입장 화면입니다(비밀번호는 해시로만 저장). 저장소가 공개라 파일 자체는 누구나 받을 수 있으므로 보안 수단이 아닙니다.
